# 22 Ángeles · sitio web

Sitio estático (HTML, CSS y JavaScript sin dependencias). Abre `index.html` o publícalo en Vercel sin configuración.

## Editar rápido
- **Contacto**: `config.js` (WhatsApp, correo y enlace de GitHub).
- **Textos de “Explora”, “Ingeniería”, comparación y viabilidad**: objetos `TECH`, `AREAS`, `RIVALS`, `PRICES` y `CATS` en `app.js`.
- **Fotos**: reemplaza los archivos conservando el nombre (por ejemplo `team-paula-torres.jpg`). Para un integrante sin foto, cambia el `<i class="avatar">` por un `<img>` en `index.html`.
- **Imagen principal**: `cad-v8.webp` / `cad-v8.png`, extraída del ensamble `Silla_V8.0/TODO.SLDASM` del repositorio y ampliada.

## Datos y fuentes
- Inversión del prototipo: tope de $4.500.000 COP, repartido según las proporciones de la hoja de gastos del equipo.
- Precios de mercado consultados en noviembre de 2026 (Falabella Colombia, whill.inc, Millercare UK). WHILL convertido con TRM de $3.310; Permobil con £1 ≈ $4.220.
- Características técnicas: repositorio https://github.com/AcePipe13/22Angeles e informe de diseño del segundo corte.

Autonomía, velocidad máxima, capacidad de carga, precio final y garantía siguen pendientes de confirmación.
